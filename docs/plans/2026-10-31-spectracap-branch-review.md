Patch A is deliberately small. Capture filenames are generated by
`BaseFetcher.save()` as `<source>_capture_<UTC timestamp>_<unique suffix>.json`.
Checking for those canonical files before opening legacy snapshots preserves
the original monthly path. It does not suppress malformed JSON once a
capture history is actually present. Manually renaming **all** of a source's
capture files outside that naming convention would no longer enable coverage
aggregation; automatic capture never does that. Preparation still uses the
stored `capture` marker and its existing filename-independent merge.
